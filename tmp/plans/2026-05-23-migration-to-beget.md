# Migration to Beget Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Перенести coordinator (Caddy + site + db-app + site-redis + Remnawave + remnanode-local) на новый Beget VPS `212.74.231.217`, оставить старый Timeweb VPS `194.87.83.31` только в роли remote-node, подключить домены `home.cyber-berezka.ru` + `admin.cyber-berezka.ru` (промежуточно через nip.io).

Спецификация: `docs/superpowers/specs/2026-05-23-migration-to-beget-design.md`.

**Tech Stack:** Docker Compose v2, Caddy 2.9, bash 5+ (idempotent scripts), Python 3.11+ (apply.py extensions, pytest), shellcheck для валидации скриптов, systemd для persistence.

```
# Cyber Berezka — Caddy reverse proxy.
# Variables:
#   SITE_HOST            — main user-facing host (home.cyber-berezka.ru или nip.io)
#   ADMIN_HOST           — panel host (admin.cyber-berezka.ru или nip.io)
#   APEX_REDIRECT_HOST   — optional apex (cyber-berezka.ru) for 301 → SITE_HOST
#   ADMIN_IP_WHITELIST   — space-separated CIDRs allowed to /api/admin/* and /admin/

{
    email {$ACME_EMAIL}
}

# === Site host =============================================================
{$SITE_HOST} {
    @blocked_clients header User-Agent *Happ*
    handle @blocked_clients {
        respond "Client not supported. Use v2RayTun, Hiddify, or NekoBox." 403
    }

    handle {
        reverse_proxy * http://site:8000
    }

    encode gzip zstd
    header {
        Strict-Transport-Security "max-age=63072000; includeSubDomains"
        X-Content-Type-Options "nosniff"
        X-Frame-Options "DENY"
        Referrer-Policy "strict-origin-when-cross-origin"
        -Server
    }
}

# === Admin host (panel + subscription endpoints) ============================
{$ADMIN_HOST} {
    @blocked_clients header User-Agent *Happ*
    handle @blocked_clients {
        respond "Client not supported." 403
    }

    # /api/sub/* — public subscription URLs. Open to everyone — VPN clients
    # outside of the admin allowlist must reach these.
    handle /api/sub/* {
        reverse_proxy http://remnawave:3000
    }

    # /admin/ and /api/admin/* — restricted to admin IPs.
    @admin_paths {
        path /admin /admin/* /api/admin/*
    }
    @admin_allowed {
        path /admin /admin/* /api/admin/*
        remote_ip {$ADMIN_IP_WHITELIST}
    }
    handle @admin_allowed {
        reverse_proxy http://remnawave:3000
    }
    handle @admin_paths {
        respond "403 Forbidden" 403
    }

    # Anything else under admin host — panel as well (REST API, OpenAPI docs etc).
    # If you want to restrict the root too, move it under @admin_paths.
    handle {
        reverse_proxy * http://remnawave:3000
    }

    encode gzip zstd
    header {
        Strict-Transport-Security "max-age=63072000; includeSubDomains"
        X-Content-Type-Options "nosniff"
        X-Frame-Options "DENY"
        Referrer-Policy "strict-origin-when-cross-origin"
        -Server
    }
}

# === Apex redirect (only when APEX_REDIRECT_HOST is set) ====================
# Caddy treats empty {$APEX_REDIRECT_HOST} as a literal empty host — the block
# becomes inert. Safe to keep enabled in both Stage 1 (empty) and Stage 2.
{$APEX_REDIRECT_HOST:placeholder.invalid} {
    redir https://{$SITE_HOST}{uri} 301
}

# === Catch-all (anti-fingerprint) ==========================================
:443 {
    tls internal
    respond 204
}
```

```python
from __future__ import annotations

import json
import subprocess
import sys
from pathlib import Path

SCRIPT = Path(__file__).resolve().parents[2] / "scripts" / "generate_xray_outbounds.py"


def run(stdin: str, *args: str) -> dict:
    result = subprocess.run(
        [sys.executable, str(SCRIPT), *args],
        input=stdin,
        capture_output=True,
        text=True,
        check=True,
    )
    return json.loads(result.stdout)


def test_ipv4_only_mode_emits_single_freedom_outbound():
    """ipv4-only mode generates one freedom outbound, no IPv6, no balancer."""
    cfg = run("", "--mode", "ipv4-only")
    assert "outbounds" in cfg
    assert "routing" in cfg

    tags = [o["tag"] for o in cfg["outbounds"]]
    # Must contain: v4-direct, direct, block. No v6-* tags.
    assert "v4-direct" in tags
    assert "direct" in tags
    assert "block" in tags
    assert not any(t.startswith("v6-") for t in tags), f"unexpected v6 outbound: {tags}"

    # No balancer in routing.
    assert cfg["routing"].get("balancers") in (None, [])
    # All IPv4 catch-all routed to v4-direct.
    rules = cfg["routing"]["rules"]
    catchall = next((r for r in rules if r.get("ip") == ["0.0.0.0/0"]), None)
    assert catchall is not None
    assert catchall["outboundTag"] == "v4-direct"
```

- [ ] **Step 3: Модифицировать `scripts/generate_xray_outbounds.py`**

Полная новая версия:

```python
#!/usr/bin/env python3
"""Generate Xray outbounds + routing config for Cyber Berezka nodes.

Modes:
  ipv6-pool (default): reads IPv6 addresses from stdin, generates one
    'freedom' outbound per IPv6 plus a random-balancer routing rule. Used
    for the old VPS where Timeweb gives us a routable /128 pool.
  ipv4-only: generates a single 'freedom' outbound that egresses via the
    server's default IPv4. Used for the new VPS that has no IPv6 pool.

Why two modes:
  The Beget VPS (new coordinator) is IPv4-only — no routable IPv6 pool
  available on the current plan. We need a profile that just sends
  everything through the single default IPv4. The old VPS keeps the
  IPv6-pool profile. See migration spec for details.

Usage:
  scripts/detect_ipv6_pool.sh | scripts/generate_xray_outbounds.py --mode ipv6-pool
  scripts/generate_xray_outbounds.py --mode ipv4-only

Exit codes:
  0 - success
  1 - empty pool on stdin (only in ipv6-pool mode)
  2 - invalid input (malformed IPv6 etc.)
"""

from __future__ import annotations

import argparse
import ipaddress
import json
import sys
from typing import Any

IPV4_ONLY_DOMAINS: list[str] = [
    "geosite:category-gov-ru",
    "domain:gosuslugi.ru",
    "domain:nalog.gov.ru",
    "domain:sberbank.ru",
    "domain:vtb.ru",
    "domain:tinkoff.ru",
    "domain:alfabank.ru",
]


def make_v6_outbound(addr: str, tag: str) -> dict[str, Any]:
    return {
        "tag": tag,
        "protocol": "freedom",
        "settings": {"domainStrategy": "UseIPv6"},
        "sendThrough": addr,
    }


def make_v4_fallback() -> dict[str, Any]:
    return {
        "tag": "v4-fallback",
        "protocol": "freedom",
        "settings": {"domainStrategy": "UseIPv4"},
    }


def make_v4_direct() -> dict[str, Any]:
    return {
        "tag": "v4-direct",
        "protocol": "freedom",
        "settings": {"domainStrategy": "UseIPv4"},
    }


def make_direct() -> dict[str, Any]:
    return {"tag": "direct", "protocol": "freedom", "settings": {}}


def make_blackhole() -> dict[str, Any]:
    return {"tag": "block", "protocol": "blackhole", "settings": {}}


def validate_pool(raw: list[str]) -> list[str]:
    out: list[str] = []
    for line in raw:
        line = line.strip()
        if not line or line.startswith("#"):
            continue
        try:
            addr = ipaddress.IPv6Address(line)
        except ValueError as exc:
            print(f"ERROR: not a valid IPv6 address: {line!r} ({exc})", file=sys.stderr)
            raise SystemExit(2) from exc
        if addr.is_link_local or addr.is_loopback or addr.is_multicast:
            print(f"ERROR: address {addr} is not global-scope", file=sys.stderr)
            raise SystemExit(2)
        out.append(str(addr))
    return out


def build_config_ipv6_pool(ipv6_pool: list[str]) -> dict[str, Any]:
    outbounds: list[dict[str, Any]] = []
    v6_tags: list[str] = []
    for idx, addr in enumerate(ipv6_pool):
        tag = f"v6-{idx:04d}"
        outbounds.append(make_v6_outbound(addr, tag))
        v6_tags.append(tag)
    outbounds.append(make_v4_fallback())
    outbounds.append(make_direct())
    outbounds.append(make_blackhole())

    routing: dict[str, Any] = {
        "domainStrategy": "IPOnDemand",
        "balancers": [
            {"tag": "v6-pool", "selector": ["v6-"], "strategy": {"type": "random"}}
        ],
        "rules": [
            {"type": "field", "ip": ["geoip:private"], "outboundTag": "block"},
            {"type": "field", "domain": IPV4_ONLY_DOMAINS, "outboundTag": "v4-fallback"},
            {"type": "field", "ip": ["::/0"], "balancerTag": "v6-pool"},
            {"type": "field", "ip": ["0.0.0.0/0"], "outboundTag": "v4-fallback"},
        ],
    }

    return {"outbounds": outbounds, "routing": routing}


def build_config_ipv4_only() -> dict[str, Any]:
    outbounds = [make_v4_direct(), make_direct(), make_blackhole()]
    routing: dict[str, Any] = {
        "domainStrategy": "IPOnDemand",
        "rules": [
            {"type": "field", "ip": ["geoip:private"], "outboundTag": "block"},
            {"type": "field", "ip": ["0.0.0.0/0"], "outboundTag": "v4-direct"},
            {"type": "field", "ip": ["::/0"], "outboundTag": "v4-direct"},
        ],
    }
    return {"outbounds": outbounds, "routing": routing}


def merge_into_config(base: dict[str, Any], generated: dict[str, Any]) -> dict[str, Any]:
    merged = dict(base)
    merged["outbounds"] = generated["outbounds"]
    merged["routing"] = generated["routing"]
    return merged


def main() -> int:
    parser = argparse.ArgumentParser(
        description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter
    )
    parser.add_argument(
        "--mode",
        choices=["ipv6-pool", "ipv4-only"],
        default="ipv6-pool",
        help="ipv6-pool: rotate over /128 IPv6 pool from stdin (default); "
        "ipv4-only: single default-IPv4 outbound, ignores stdin",
    )
    parser.add_argument("--merge", metavar="PATH", help="Merge into existing config")
    parser.add_argument("--indent", type=int, default=2)
    args = parser.parse_args()

    if args.mode == "ipv6-pool":
        raw_lines = sys.stdin.read().splitlines()
        pool = validate_pool(raw_lines)
        if not pool:
            print("ERROR: empty IPv6 pool on stdin", file=sys.stderr)
            return 1
        generated = build_config_ipv6_pool(pool)
    else:
        generated = build_config_ipv4_only()

    if args.merge:
        try:
            with open(args.merge, encoding="utf-8") as f:
                base = json.load(f)
        except (OSError, json.JSONDecodeError) as exc:
            print(f"ERROR: cannot read base config {args.merge!r}: {exc}", file=sys.stderr)
            return 2
        output = merge_into_config(base, generated)
    else:
        output = generated

    json.dump(output, sys.stdout, indent=args.indent or None, ensure_ascii=False)
    sys.stdout.write("\n")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
"""Reality key rotation helpers for apply.py."""
from __future__ import annotations

from pathlib import Path
from typing import Tuple


def rotate_reality_keys(client) -> Tuple[str, str]:
    """Call Remnawave x25519 generate endpoint, return (private, public).

    Closes spec task #28 (Reality key regen).
    """
    response = client.generate_x25519()
    return response["privateKey"], response["publicKey"]


def write_keys_to_env(env_path: Path, private_key: str, public_key: str) -> None:
    """Write REALITY_PRIVATE_KEY and REALITY_PUBLIC_KEY to .env, in-place.

    Replaces existing lines if present, appends otherwise. Creates the file
    if it does not exist. Preserves all other lines and ordering.
    """
    if not env_path.exists():
        env_path.write_text(
            f"REALITY_PRIVATE_KEY={private_key}\nREALITY_PUBLIC_KEY={public_key}\n"
        )
        return

    lines = env_path.read_text().splitlines()
    have_priv = False
    have_pub = False
    out: list[str] = []
    for line in lines:
        if line.startswith("REALITY_PRIVATE_KEY="):
            out.append(f"REALITY_PRIVATE_KEY={private_key}")
            have_priv = True
        elif line.startswith("REALITY_PUBLIC_KEY="):
            out.append(f"REALITY_PUBLIC_KEY={public_key}")
            have_pub = True
        else:
            out.append(line)

    if not have_priv:
        out.append(f"REALITY_PRIVATE_KEY={private_key}")
    if not have_pub:
        out.append(f"REALITY_PUBLIC_KEY={public_key}")

    env_path.write_text("\n".join(out) + "\n")
```

- [ ] **Step 1: Создать скрипт**

```bash
#!/usr/bin/env bash
# Single entry-point for the full migration pipeline.
# Two manual pause points (Remnawave first-admin registration + API token paste)
# are inevitable architectural constraints. All other steps are automated.
set -euo pipefail

NEW_HOST="${NEW_HOST:-212.74.231.217}"
OLD_HOST="${OLD_HOST:-194.87.83.31}"
LOCAL_BASE="$(cd "$(dirname "$0")/.." && pwd)"

confirm() {
    local prompt="$1"
    read -r -p "${prompt} [y/N] " resp
    [[ "${resp}" =~ ^[Yy]$ ]] || { echo "Aborted."; exit 1; }
}

echo "===================================================="
echo "  Cyber Berezka — full migration pipeline"
echo "  New (coordinator): ${NEW_HOST}"
echo "  Old (node-only):   ${OLD_HOST}"
echo "===================================================="

echo "===> [1/9] Sanity-check SSH access"
ssh -o BatchMode=yes -o ConnectTimeout=5 "root@${NEW_HOST}" 'echo OK' >/dev/null
ssh -o BatchMode=yes -o ConnectTimeout=5 "root@${OLD_HOST}" 'echo OK' >/dev/null
echo "    SSH OK on both servers"

echo "===> [2/9] Sync repo to NEW server"
bash "${LOCAL_BASE}/scripts/sync_repo_to_server.sh" "${NEW_HOST}"

echo "===> [3/9] Provision NEW server"
ssh "root@${NEW_HOST}" 'bash /root/cyber-berezka/scripts/provision_new_server.sh'

echo "===> [4/9] MANUAL PAUSE — first admin registration"
echo "    Open https://admin.212-74-231-217.nip.io in a browser."
echo "    Register the admin user (username: z1kurat or as you prefer)."
echo "    NOTE: certificate may take ~60s to issue via Let's Encrypt."
confirm "Done?"

echo "===> [5/9] MANUAL PAUSE — paste Remnawave API token"
echo "    In Remnawave UI, go to Settings → API tokens → Generate."
echo "    Copy the token."
ssh -t "root@${NEW_HOST}" 'python3 /root/cyber-berezka/infra/remnawave/bootstrap_token.py'

echo "===> [6/9] Sync repo to OLD server"
bash "${LOCAL_BASE}/scripts/sync_repo_to_server.sh" "${OLD_HOST}"

echo "===> [7/9] Teardown old coordinator stack"
ssh "root@${OLD_HOST}" 'bash /root/cyber-berezka/scripts/teardown_old_server.sh'

echo "===> [8/9] Reconfigure OLD as remote node"
echo "    NOTE: NODE_SECRET_KEY in ${OLD_HOST}:/root/cyber-berezka/infra/.env"
echo "    must match what Remnawave panel issued for this node."
confirm "NODE_SECRET_KEY set in old server's .env?"
ssh "root@${OLD_HOST}" 'bash /root/cyber-berezka/scripts/reconfigure_old_as_node.sh'

echo "===> [9/9] Final status"
ssh "root@${NEW_HOST}" 'cd /root/cyber-berezka/infra/remnawave && python3 apply.py status'

echo "===================================================="
echo "  Migration complete."
echo "  Verify with scripts/_verify_migration.sh (task #48)."
echo "  Next: rotate Reality keys via apply.py rotate-reality-key"
echo "===================================================="
```
